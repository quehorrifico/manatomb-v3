## Actual adapter boundary

`FModel.initialize` → `RegisteredPlayer.forCommander` with `LobbyPlayerHuman` and `GamePlayerUtil.createAiPlayer` → `Match.createGame` → actual `PlayerControllerHuman.setGui(IGuiGame proxy)` → `Match.startGame` on a dedicated game thread. `GameRules(Commander)` and Commander variants stay in Forge. The adapter does not subclass the controller, replace its queue, evaluate card rules or synthesize a CPU turn.

Queued human input uses **InputQueue / InputProxy / InputSynchronized / InputBase**. Browser actions resolve current DTO IDs to retained `CardView`/`PlayerView` handles inside the worker and call **selectButtonOk, selectButtonCancel, selectCard, selectPlayer**. All browser callbacks to those controller methods run on the real Swing EDT. **GameAction.invoke is not treated as a per-game executor**: upstream may execute inline or on a shared cached game pool.

Input publication waits for the UI render callback's `showPromptMessage` paint generation and matching queue/proxy/painted input. Observing `InputQueue.setInput` alone is insufficient because it publishes before awaiting the latch. The final adapter suppresses republication while a controller action is in flight; otherwise a previously queued repaint could admit another command based on pre-action state. `InputPayMana.isActivatingManaAbility()` also suppresses publication until its cached-pool activation callback updates the message. Arbitrary life/card updates do not reopen input.

Session UUID + prompt UUID + monotonic revision bind an immutable published DTO to one pending choice. Under a gate, admission checks those identities, allowed controls/IDs and replay state, then consumes the generation **before** enqueueing a command. Synchronous GUI callbacks publish a typed choice and wait on a `CompletableFuture`; the HTTP pool completes it directly after validation. Neither a waiting EDT nor game thread must execute the reply callback itself. No lock is held across the future wait. A waiting return-value prompt may be published during an in-flight controller call, which is essential to avoid deadlock.

The HTTP server binds **127.0.0.1 only**, checks exact Host and POST Origin, uses a per-process token, caps request bodies, exports a JSON string snapshot and has no raw-state endpoint, filesystem/API proxy or CORS support. DTOs contain explicit allowed primitive fields. This is local containment, not signed-in production authorization or a hardened public service.
